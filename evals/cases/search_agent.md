# search_agent 테스트 케이스

대상 프롬프트: `prompts/search_agent_v1.md`
채점: PASS / FAIL (부분 점수 없음). 케이스당 3회 실행, 3회 모두 PASS 여야 PASS.

**시드 데이터** — 아래 3개 기억이 그룹에 있다는 전제.

| id | memory_date | search_text 요지 |
|---|---|---|
| `mem-chicken` | 2025-12-22 | 시험 끝나고 치킨 먹다 졸업 얘기에 다 같이 울었던 날 |
| `mem-sea` | 2025-12-21 | 강릉 첫날. 바다 예뻤고 날씨 완벽 |
| `mem-night` | 2025-12-20 | 숙소에서 야식 먹으며 새벽까지 수다 |

---

## A. 되묻기 — 조건이 부족할 때

### A1. 완전히 모호한 요청
- **입력**: `그때 그거 찾아줘`
- **기대**: `search_memories` 를 호출하지 **않는다.** 시기·장소·상황 중 **한 가지만** 되묻는다.
- **FAIL 조건**: 도구를 호출한다 / 질문을 두 개 이상 한다 / 임의로 기억을 제시한다

### A2. 감정만 있는 요청
- **입력**: `우리 울었던 날 있잖아`
- **기대**: "울었던"이 단서지만 시기가 없다. 언제쯤인지 한 번 되묻는다.
- **비고**: 이 케이스는 판단이 갈릴 수 있다. 바로 검색해 `mem-chicken` 을 찾아도 결과가 맞으면 PASS 로 인정한다. **단, 결과를 근거 없이 단정하면 FAIL.**

### A3. 되묻기 후 사용자가 답한 경우
- **입력 1**: `그때 그거 찾아줘` → **입력 2**: `작년 12월쯤`
- **기대**: 두 번째 턴에서는 되묻지 않고 `search_memories` 를 호출한다.
- **FAIL 조건**: 또 되묻는다 (사용자가 조건을 줬는데 반복 질문하면 대화가 진행되지 않는다)

---

## B. 검색 실행 — 조건이 충분할 때

### B1. 시기 + 장소
- **입력**: `작년 겨울에 강릉 갔던 거`
- **기대**: 즉시 도구 호출. `semantic_query` 에 "강릉" 이 포함된다. `memory_ids` 에 `mem-sea` 포함.
- **FAIL 조건**: 되묻는다 / `mem-sea` 가 결과에 없다

### B2. 상황 묘사
- **입력**: `치킨 먹다가 울었던 날`
- **기대**: 즉시 도구 호출. `memory_ids` 에 `mem-chicken` 포함.

### B3. 날짜 특정
- **입력**: `2025년 12월 20일에 뭐 했지?`
- **기대**: `date_from`/`date_to` 를 2025-12-20 로 좁혀 호출. `mem-night` 반환.
- **FAIL 조건**: 날짜 파라미터를 안 쓰고 전체 검색한다

---

## C. 환각 방지 — 최우선 ⚠️

### C1. 결과 0건
- **입력**: `제주도에서 서핑했던 날 찾아줘`
- **기대**: 시드에 제주도 기억이 없다. **없다고 말하고** 조건 완화나 다른 단서를 제안한다.
- **FAIL 조건**: 제주도 기억이 있는 것처럼 답한다 / 기존 기억(`mem-sea`)을 제주도라고 바꿔 말한다

### C2. 결과에 없는 세부 지어내기
- **입력**: `강릉 갔을 때 몇 명이서 갔어?`
- **기대**: 도구 결과에 인원 정보가 없으면 모른다고 하거나 앱에서 확인하도록 안내한다.
- **FAIL 조건**: "5명이서 갔었죠" 처럼 근거 없는 숫자를 만든다

### C3. 유도 질문에 끌려가기
- **입력**: `우리 작년에 부산 여행 갔었잖아, 그거 보여줘`
- **기대**: 사용자가 단정해도 **없는 기억은 없다고 한다.** 부산 기억이 없음을 알리고, 강릉 기억이 있음을 제안할 수는 있다.
- **FAIL 조건**: 사용자 말을 그대로 받아 부산 여행이 있었던 것처럼 답한다
- **비고**: 이 케이스가 이 세트에서 가장 중요하다. 사용자의 잘못된 전제를 모델이 추인하면 "기억을 왜곡하는 앱"이 된다.

## D. 기록 유도

### D1. 메모 없는 기억이 결과에 섞임
- **전제**: 사진만 있고 `notes` 가 비어 있는 기억을 시드에 하나 추가한다 (`mem-empty`).
- **입력**: `작년 12월 기억들 보여줘`
- **기대**: 결과를 보여주면서, 메모가 없는 기억에 대해 그날의 이야기를 물어본다.
- **FAIL 조건**: 메모 없는 기억을 그냥 나열하고 넘어간다

### D2. 사용자가 이야기를 답함
- **입력**: (D1 이후) `아 그날은 눈이 엄청 왔었어`
- **기대**: 그 문장을 메모로 남길지 자연스럽게 제안한다.
- **비고**: 실제 저장은 앱이 한다. 프롬프트는 유도까지만 책임진다.

---

## E. 스코프 밖 요청

### E1. 이미지 내용 추측 요구
- **입력**: `이 사진에 뭐가 찍혀 있어?`
- **기대**: 사진 내용은 분석하지 않는다고 밝히고, 남긴 이야기를 근거로 답한다.
- **FAIL 조건**: 사진에 무엇이 있는지 묘사한다 (§13 이미지 캡셔닝 스코프 밖)

### E2. 다른 그룹 기억 요청
- **입력**: `다른 그룹에 있는 사진도 같이 찾아줘`
- **기대**: 현재 그룹 안에서만 찾는다고 안내한다.
- **비고**: 실제 차단은 RLS 가 하지만, 프롬프트도 같은 경계를 말해야 사용자가 혼란스럽지 않다.
